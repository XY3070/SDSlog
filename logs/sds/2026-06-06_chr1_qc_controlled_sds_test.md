# 2026-06-06 chr1 QC Controlled SDS Test

## Question

After extending the rebuilt SDS input QC contract, test whether the chr1
`peak125` / `peak143` artifact is controllable when the new `SDSpipeline`
workflow applies variant-level QC and singleton-specific QC in controlled arms.

This is a targeted chr1 test, not a genome-wide release gate.

## Controlled Arms

All arms used the same VCF, sample list, gamma file, baseline input, target BED,
and compute settings. Only the named QC switch changed.

| Arm | Changed factor |
| --- | --- |
| `baseline` | no post-filter; target `t_file` only |
| `mask_only` | analysis mask only |
| `variant_only` | call rate, QUAL, DP_AVG, ExcHet/HWE, AC for singleton |
| `singleton_density_only` | 20 kb / 10 kb sliding-window singleton density, `mean + 4 SD` |
| `excess_sample_only` | sample singleton count, `mean + 4 SD` |
| `observability_callrate_only` | `o_file` from target test-SNP call rate |
| `final_cumulative` | mask + variant QC + singleton density + excess-sample + callrate observability |

Compute command template:

```bash
bash SDSpipeline/scripts/run_sds_compute.sh \
  --pop NCN \
  --chr 1 \
  --in-root "$RUN_ROOT/input_target/$arm" \
  --out-root "$RUN_ROOT/output_target/$arm" \
  --g-file "$G_FILE" \
  --force \
  --chunk-rows 1000 \
  --max-parallel-chunks 4
```

## Interpretation

The chr1 `peak125` / `peak143` artifact is controllable.

- `mask_only` removes both peak windows while preserving the control window.
- `singleton_density_only` also removes both peak windows independently,
  showing that the artifact is visible directly in singleton-density QC.
- `variant_only` is not sufficient; the peak windows remain with similar or
  slightly worse extreme counts.
- `excess_sample_only` slightly changes row counts and extremes but does not
  solve the artifact.
- `observability_callrate_only` has negligible impact in this targeted test.
- `final_cumulative` removes both peak windows and keeps the control window
  essentially unchanged.

The result improves the specific chr1 artifact behavior, but it is not yet a
paper-facing SDS release. The control window still contains some extreme raw
`rSDS` values, and genome-wide mask, low-mappability/LCR resources,
normalization acceptance, orthogonal validation, and gamma provenance remain
required before broad conclusions.
